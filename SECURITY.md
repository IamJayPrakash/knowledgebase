# Security Policy

## Supported Versions

Security updates and vulnerability patches are applied to the latest revision of the `main` branch.

| Branch | Supported |
| :--- | :--- |
| `main` | :white_check_mark: |
| Old Releases / Tags | :x: |

## Reporting a Vulnerability

If you discover a potential security vulnerability (e.g. exposed credentials, sensitive scripts, or XSS vectors in the web documentation portal):

1. **Do NOT open a public GitHub issue.**
2. Please report the vulnerability privately via GitHub Security Advisories at:
   `https://github.com/IamJayPrakash/knowledgebase/security/advisories/new`
   or contact the repository maintainer directly.
3. Include detailed reproduction steps, impact assessment, and potential mitigation strategies.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a timely resolution before disclosure.
